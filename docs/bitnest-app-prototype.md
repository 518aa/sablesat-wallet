# BitNest 应用原型图

## 设计方向

BitNest 是面向新手的 BTC 自托管钱包。原型采用“安静的金融工具”风格：深色为主、琥珀色作为比特币识别色、青绿色用于安全和到账反馈、蓝色用于链上网络状态。界面避免营销化大图，强调余额、下一步操作和风险提示。

## 视觉系统

- 背景：深海军蓝 `#090E1A`，浅色模式为暖白 `#F6F2EA`
- 主色：比特币琥珀 `#F5A524`
- 辅助色：青绿 `#2DD4BF`、链上蓝 `#3B82F6`
- 圆角：核心卡片 8px，底部导航 8px，符合工具型应用的克制感
- 排版：大号余额 + 紧凑的操作区 + 可扫描的列表
